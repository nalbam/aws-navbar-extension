## Full Description

```
Easily identify your current AWS region at a glance with colorful navigation bar gradients and country flags.

⸻

THE PROBLEM

When working across multiple AWS regions, it's easy to accidentally deploy resources to the wrong location. The default AWS Console provides minimal visual distinction between regions.

⸻

THE SOLUTION

AWS Colorful Navbar transforms your AWS Console experience with clear visual indicators.

🎨 Dynamic Color Gradients
• Each region displays a unique gradient inspired by its country's flag
• Global services (IAM, CloudFront, Route 53) display globe colors
• Instantly recognize your current region without reading text
• Customize colors with the built-in color picker (2-4 colors)

👁️ Readable by Design
• Two styles: Vivid (flag colors, white text) and Subtle (pastel flag colors, dark text)
• Navbar text keeps at least 4.5:1 contrast (WCAG AA) for every region and custom color
• Made for the new AWS Console design; keeps the AWS account color

🏳️ Regional Flags
• Country flags appear next to the region selector and in the region menu
• 29 countries and 38+ AWS regions supported

⚡ Features
• Real-time color updates
• Per-region color customization
• Dark/Light theme interface
• Lightweight and privacy-focused
• No data collection

🌍 Supported Regions
US, Europe, Asia Pacific, South America, Middle East, Africa, Canada, and all commercial AWS regions.

⸻

Reduce deployment errors. Work confidently across regions.

Open Source: https://github.com/nalbam/aws-navbar-extension
```

### 전체 설명

```
AWS 리전을 한눈에 구별하세요. 국가별 그라데이션 색상과 국기로 현재 리전을 즉시 확인할 수 있습니다.

⸻

문제점

여러 AWS 리전에서 작업할 때, 실수로 잘못된 리전에 리소스를 배포하기 쉽습니다. 기본 AWS 콘솔은 리전 간 시각적 구별이 어렵습니다.

⸻

해결책

AWS Colorful Navbar는 명확한 시각적 표시로 AWS 콘솔 경험을 개선합니다.

🎨 동적 색상 그라데이션
• 각 리전마다 국기 색상 기반의 고유한 그라데이션 표시
• 글로벌 서비스(IAM, CloudFront, Route 53)는 지구본 색상 표시
• 텍스트를 읽지 않고도 현재 리전을 즉시 인식
• 색상 선택기로 원하는 색상 커스터마이징 (2-4색)

👁️ 읽기 쉬운 디자인
• 두 가지 스타일: 선명(Vivid, 국기 색 + 흰 글자)과 은은(Subtle, 연한 국기 색 + 어두운 글자)
• 모든 리전과 사용자 색상에서 네비바 글자 대비 4.5:1 이상 유지 (WCAG AA)
• 새 AWS 콘솔 디자인 지원, AWS 계정 색상 유지

🏳️ 리전 국기
• 리전 선택기 옆과 리전 메뉴에 국기 표시
• 29개국 38개 이상 AWS 리전 지원

⚡ 주요 기능
• 실시간 색상 업데이트
• 리전별 색상 커스터마이징
• 다크/라이트 테마 지원
• 가볍고 개인정보 보호 중심
• 데이터 수집 없음

🌍 지원 리전
미국, 유럽, 아시아 태평양, 남미, 중동, 아프리카, 캐나다 등 모든 AWS 상용 리전

⸻

잘못된 리전 배포 실수를 방지하세요. 자신있게 작업하세요.

오픈소스: https://github.com/nalbam/aws-navbar-extension
```
